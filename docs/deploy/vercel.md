# Online demo on Vercel (free Hobby plan)

The public demo is a **fixtures-only**, read-only build of METAL. It contains no real recordings, voices, usernames, databases, secrets or model weights, so nothing private can be reached through it.

## How it's switched on

Fixture mode is on whenever `VERCEL=1`, which Vercel sets for every build and function, or when `METAL_PUBLIC_DEMO=fixtures` is set. No environment variables need to be configured. See `src/server/public-demo.ts`.

| | Fixture mode |
|---|---|
| Database | An empty in-memory SQLite per function instance. Nothing is read from or written to disk. |
| Writes | Every `POST`/`PUT`/`PATCH`/`DELETE` is refused with 403 in `src/proxy.ts` |
| API | Only `GET /api/capture` (the shell's status widget) and `GET /api/health` answer; everything else returns 403 |
| Real-library pages | `/recall` → `/recall/demo`, `/sessions` → `/sessions/demo`, `/povs` → `/povs/demo`, `/studio` → `/studio?demo=1`; `/import`, `/sources`, `/settings`, `/clips`, `/status`, `/recordings/*` → `/local-only` |
| Models | None shipped. `next.config.ts` keeps onnxruntime, transformers.js and sharp out of the functions on Vercel |

## What works, what's simulated

| Feature | Online demo |
|---|---|
| Showcase and guided tour | Works. The tour's four stops are the fixture pages, and each tip says what's fictional |
| Recall | **Live keyword search** over fictional demo memories. Speech, meaning and scene search (Visual Recall, experimental) need real recordings and local models, so they're local-only |
| Time Machine and Relive | Fictional nights, with illustrated stills (no video) |
| Multi-POV | **Real playback, switching and side by side** of two synthetic clips generated by `scripts/public-demo/make-pov-demo.mts`. The offset shown is what METAL's audio sync measured on them at build time (labelled as such); it isn't re-measured online |
| Story Studio | A fictional story you can rearrange, trim and caption in the browser; nothing is saved, and MP4 export is local-only |
| Capture, import, Smart Clip, transcription, exports | Local-only; the pages say so |

## Set up automatic deployments (GitHub integration)

1. Sign in at vercel.com → **Add New… → Project → Import Git Repository** → pick `alui712/metal`. Grant the Vercel GitHub app access to that one repository; Hobby supports private repos.
2. Framework preset: **Next.js**. Leave the build command and output directory at their defaults, and add **no** environment variables.
3. **Settings → Git → Production Branch:** `release/public-clean`, or `main` once it's merged with your approval.
4. Keep **Deployment Protection** (Vercel Authentication) on for preview deployments. Every other branch push then gets a private preview, and only the production branch is public.
5. Optionally add a custom domain under **Settings → Domains**.

CLI alternative (already logged in): from a clean export of the branch, run `npx vercel@65 deploy` for a protected preview, or `npx vercel@65 deploy --prod` to publish.

## Free-plan fit

There are no paid add-ons, databases or storage. Static pages and the two clips (~0.5 MB) are served from Vercel's CDN, and each function stays far below the 250 MB limit because the AI runtimes are excluded. Hobby is for personal, non-commercial use, which suits a portfolio.
